## 1.0.0

First public release.

Copy stored JPEG and PNG previews from TIFF-family RAW (DNG, CR2, NEF, ARW, ORF, RW2, PEF), Fujifilm RAF, Canon CR3, JPEG EXIF thumbnails, and Photoshop PSD/PSB. Node.js 20+ CLI and path API; browser build from a `Uint8Array`. No runtime dependencies.
